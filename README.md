# Nail Salon Bot — Demo

Демо-версия Telegram-бота для nail-мастеров. Используется для презентации продукта клиентам перед разработкой — клиент видит как будет работать его бот и вносит правки до старта.

## Что умеет бот

**Для клиентов:**
- Запись к мастеру с выбором услуги и свободного окошка
- Каталог услуг с фото, описанием, ценой и временем выполнения
- Карусель примеров работ
- Оплата через СБП с автоматической проверкой через Gemini AI

**Для администратора:**
- Добавление и редактирование услуг (фото, цена, описание, длительность)
- Управление свободными окошками для записи
- Просмотр всех записей клиентов

## Стек

- **Python** + aiogram
- **База данных** — SQLite
- **AI** — Gemini Flash API (проверка оплаты)
- **Деплой** — Railway

## Запуск локально

**1. Клонируй репозиторий**
```bash
git clone https://github.com/fukdat/demonail-salon-bot.git
cd demonail-salon-bot
```

**2. Установи зависимости**
```bash
pip install -r requirements.txt
```

**3. Создай `.env` файл**
```
BOT_TOKEN=your_telegram_bot_token
ADMIN_ID=your_telegram_id
GEMINI_API_KEY=your_gemini_api_key
SBP_PHONE=your_phone_number
SBP_BANK=your_bank_name
```

**4. Запусти бота**
```bash
python bot.py
```

## Как это работает в продажах

1. Клиент интересуется ботом для своего салона
2. Я даю ссылку на этот демо-бот — он пробует его сам
3. Обсуждаем правки под его бизнес
4. Разрабатываю финальную версию с его брендингом и базой данных
